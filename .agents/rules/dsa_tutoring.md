# DSA Tutoring Guidelines: WHAT-WHY-HOW Framework

## Target Student Profile
- Absolute beginner to both C++ and Data Structures & Algorithms.
- Goal: University/College semester exams (theory + viva + practical coding) and strong conceptual foundation.

## Mandatory Teaching Structure for Every Lesson:
1. **WHAT**:
   - Clear definition, real-world analogy, visual diagrams (ASCII / memory layout).
2. **WHY**:
   - Motivation: Why do we need this data structure/algorithm?
   - Practical real-world use case vs naive alternatives.
   - Time and space complexity trade-offs.
3. **HOW**:
   - Step-by-step algorithm explanation.
   - Clean, well-commented C++ implementation (`.cpp` file).
   - Step-by-step dry run table tracing variables with sample inputs.
4. **🎓 College Exam Corner**:
   - Typical 5/10-mark university exam questions & model answers.
   - Code tracing / Dry run questions.
   - Viva voice questions and common exam traps/mistakes.

## Git & Repository Workflow:
- Maintain a structured folder hierarchy (e.g., `00_cpp_basics/`, `01_time_space_complexity/`, `02_arrays/`, etc.).
- Update `README.md` progress tracker as topics are completed.
- Commit code and notes to git with clear messages after each lesson, and push to GitHub remote when connected.
